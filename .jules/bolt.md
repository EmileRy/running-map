## 2025-05-15 - [Optimize track filtering and map rendering]
**Learning:** Parsing ISO date strings into numeric timestamps (`new Date().getTime()`) inside React's render loop or `useMemo` blocks is a significant bottleneck when handling thousands of tracks during frequent updates (e.g., range slider moves). Moving this computation to the server-side data fetching layer allows for O(1) numeric comparisons in the UI. Additionally, Leaflet's default SVG renderer struggles with thousands of polylines; enabling `preferCanvas: true` drastically improves panning and zooming performance by flattening vectors into a single canvas element.
**Action:** Always pre-calculate derived numeric values on the server when they are used in high-frequency UI interactions. Use Leaflet's Canvas renderer for map-heavy applications.
