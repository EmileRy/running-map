## 2025-07-03 - [Pre-calculated Timestamps and Leaflet Canvas Optimization]
**Learning:** For map-heavy applications with a temporal dimension (like a slider filtering thousands of tracks), O(N) date parsing in the render path is a significant bottleneck. Standard SVG rendering in Leaflet also hits a performance ceiling quickly when dealing with thousands of polylines. Additionally, React 19 / Next 16 enforces strict purity and non-cascading render rules (e.g., `react-hooks/set-state-in-effect`) that require careful handling of state updates in effects.
**Action:** Always pre-calculate numeric timestamps on the server (or once upon data receipt) to allow O(1) comparison during frequent UI updates. Use `preferCanvas: true` for Leaflet maps with large street/track sets. When dealing with React 19, defer state updates in effects using `setTimeout(..., 0)` or microtasks to avoid cascading render warnings, and ensure `Date.now()` is not called directly in the render body by capturing it in effects or state.
